# Huawei Cloud ECS

**STOP — Do not answer from general knowledge.** Follow the procedure below.

## Overview
Domain expertise for Huawei Cloud Elastic Cloud Server (ECS). Covers instance lifecycle, flavor selection, image management, networking, storage attachment, auto-scaling, and troubleshooting.

## Critical Warnings
- **Flavor 区域可用性**: 不是所有 flavor 在所有区域可用——先用 hcloud ecs list-flavors --region <region> 检查
- **安全组默认规则**: 新安全组默认拒绝所有入站流量——必须显式添加规则
- **EIP 计费**: 未绑定到运行中实例的 EIP 仍然计费
- **按需 vs 包周期**: 按需实例关机后仍计费（除非是"关机不收费"的特定 flavor）
- **云硬盘独立生命周期**: 删除实例时默认不删除系统盘——需要 delete_on_termination 参数

## Flavor 选择指南
| 使用场景 | 推荐规格族 | 示例 |
|----------|-----------|------|
| Web 应用/微服务 | s6 (通用型) | s6.large.2 (2vCPU/4GB) |
| 数据库/大数据 | m6 (内存优化) | m6.xlarge.8 (4vCPU/32GB) |
| AI推理/科学计算 | g6 (GPU) | g6.2xlarge.8 (8vCPU/64GB + 1×T4) |
| 高性能计算 | h6 (高IO) | h6.2xlarge.8 (8vCPU/64GB + 本地SSD) |

## Common Workflows
| 任务 | 命令 | 详细步骤 |
|------|------|----------|
| 创建实例 | hcloud ecs create --flavor s6.large.2 --image CentOS-7.9 --vpc-id xxx --subnet-id xxx | references/create-instance.md |
| 绑定EIP | hcloud eip bind --public-ip xxx.xxx.xxx.xxx --instance-id xxx | references/eip.md |
| 配置安全组 | hcloud security-group add-rule --direction ingress --port 22 --protocol tcp | references/security-group.md |
| 挂载云硬盘 | hcloud evs attach --volume-id xxx --instance-id xxx | references/evs.md |
| 弹性伸缩 | hcloud as create-group --configuration xxx | references/auto-scaling.md |

## Troubleshooting
| 错误 | 根因 → 修复 |
|------|------------|
| 实例无法 SSH 连接 | 安全组未开放 22 端口 → 添加入方向规则; EIP 未绑定 → hcloud eip bind |
| flavor 不可用 | 当前区域不支持 → hcloud ecs list-flavors --region xxx |
| 资源不足 | 区域库存不足 → 换规格或区域 |
| 系统盘空间不足 | 初始配置过小 → 扩容云硬盘 hcloud evs resize |

## Security Considerations
- MUST use security groups for access control (not iptables)
- MUST store SSH key pairs in DEW; NEVER hardcode in user-data scripts
- SHOULD use anti-DDoS (AAD) for internet-facing instances
- SHOULD enable CTS audit logging (hcloud cts tracker)

## Additional Resources
- ECS 产品文档: https://support.huaweicloud.com/ecs/
- Flavor 规格表: references/flavors.md

# Huawei Cloud OBS

**STOP — Do not answer from general knowledge.** Follow the procedure below.

## Overview
Domain expertise for Huawei Cloud Object Storage Service (OBS). Covers bucket/object lifecycle, access control, replication, hosting, and presigned URLs.

## Critical Warnings
- **桶名全局唯一**: 所有华为云用户共享桶命名空间——选择足够独特的名称
- **权限模型三层**: IAM 策略 > 桶策略 > ACL——冲突时最严格生效
- **一致性模型**: OBS 自 2021 年起支持**强一致性（read-after-write）**——PUT 后立即 GET 保证读到最新版本
- **版本控制不可逆**: 开启后无法关闭，只能暂停
- **删除桶前清空**: 非空桶无法删除——包括所有版本和删除标记

## Common Workflows
| 任务 | 命令 | 详细步骤 |
|------|------|----------|
| 创建桶 | hcloud obs createbucket --bucket <name> --location cn-south-1 | references/bucket-lifecycle.md |
| 配置静态网站 | hcloud obs website --bucket <name> --index index.html | references/static-website.md |
| 配置生命周期 | hcloud obs lifecycle --bucket <name> --rule '{\"transitions\":[...]}' | references/bucket-lifecycle.md |
| 生成预签名 URL | hcloud obs presign --bucket <name> --key <object> --expires 3600 | references/auth.md |
| 跨区域复制 | hcloud obs replication --bucket <name> --dest-region cn-north-1 | references/replication.md |

## 权限模型 (IAM > Bucket Policy > ACL)
| 层级 | 作用域 | 使用场景 |
|------|--------|----------|
| IAM Policy | 用户/用户组级 | 跨桶权限管理 (推荐) |
| Bucket Policy | 桶级 | 跨账号授权、公网访问 |
| ACL | 对象级 | 精细到单个对象 (传统模式) |

## Security Considerations
- MUST block public access by default (PublicAccessBlockConfiguration)
- MUST use IAM policies over ACL for access control
- SHOULD enable SSE-KMS (DEW) encryption at rest
- SHOULD enable HTTPS-only access
- MUST NOT embed AK/SK in presigned URL generation code

## Additional Resources
- OBS 产品文档: https://support.huaweicloud.com/obs/

## 3. huawei-iam (统一身份认证)

**对标**: aws-iam

**核心规则** (直接移植 aws-iam 的设计):
- **最小权限**: 从零开始逐条添加，禁止 * 通配符
- **不用长期 AK/SK**: 企业项目用 Agency (委托)，个人用临时凭证
- **策略结构**: Effect → Action → Resource → Condition
- **混淆代理人保护**: g:SourceAccount + g:SourceUrn 条件键

**华为云 IAM 特有的三种策略**:
| 策略类型 | 作用域 | 对比 AWS |
|----------|--------|----------|
| 系统策略 (System Policy) | 全局预定义 | AWS Managed Policy |
| 自定义策略 (Custom Policy) | 用户自定义 | AWS Customer Managed Policy |
| 项目级策略 (Project Policy) | 项目内 | AWS Resource-Based Policy (近似) |

**Key Agent 指令**:
> "华为云 IAM 的策略格式与 AWS 不同——Action 前缀是服务名缩写 (如 ecs:servers:create 不是 ecs:RunInstances)。永远先查 references/actions.md 获取精确的 Action 名称。"

# Huawei Cloud CLI Setup

**STOP — Do not answer from general knowledge.** KooCli installation methods and prerequisites change. Follow this procedure exactly.

## Overview

Get the Huawei Cloud CLI (KooCli / hcloud) installed and authenticated so you can manage cloud resources from the command line.

## Prerequisites

- Internet access to download KooCli
- A Huawei Cloud account with IAM permissions
- AK/SK (Access Key / Secret Key) or IAM user credentials

## Step 1: Install KooCli

### Windows (PowerShell, Administrator)

```powershell
# Download installer
Invoke-WebRequest -Uri "https://hwcloudcli.obs.cn-north-1.myhuaweicloud.com/cli/latest/hcloud_install.exe" -OutFile "$env:TEMP\hcloud_install.exe"

# Run installer
Start-Process -FilePath "$env:TEMP\hcloud_install.exe" -Wait

# Verify
hcloud version
```

### Linux / macOS

```bash
# One-line install via official script
curl -sSL https://hwcloudcli.obs.cn-north-1.myhuaweicloud.com/cli/latest/hcloud_install.sh -o hcloud_install.sh && bash hcloud_install.sh

# Or via pip
pip install hcloud

# Verify
hcloud version
```

### macOS (Homebrew)

```bash
brew install hcloud
hcloud version
```

### Docker

```bash
docker run -it --rm \
  -v ~/.huaweicloud:/root/.huaweicloud \
  huaweicloud/hcloud:latest \
  hcloud version
```

## Step 2: Initial Configuration

```bash
# Interactive configuration (recommended)
hcloud configure init

# Follow prompts:
# 1. Enter AK (Access Key)
# 2. Enter SK (Secret Key)
# 3. Select default region (e.g., cn-south-1)
# 4. Select output format (json recommended)
```

Or non-interactive:

```bash
hcloud configure set --ak=<AK> --sk=<SK> --region=cn-south-1
hcloud configure set --output=json
```

## Step 3: Verify

```bash
# Check current config
hcloud configure list

# Test authentication
hcloud iam get-account-summary

# List available regions
hcloud ecs list-flavors --region cn-south-1
```

**Expected**: Returns account summary or flavor list. No authentication errors.

## Prerequisites Check Table

| Check | Command | Expected |
|-------|---------|----------|
| CLI installed | `hcloud version` | >= 3.0.0 |
| Configured | `hcloud configure list` | Shows AK/region/output |
| Authenticated | `hcloud iam get-account-summary` | Returns account info |
| Network OK | `hcloud ecs list-flavors --region cn-south-1` | Returns flavor list |

## Troubleshooting

| Error | Root Cause -> Fix |
|-------|-------------------|
| `hcloud: command not found` | Not installed or not in PATH -> Reinstall or add to PATH |
| `AccessDenied` / `AuthFailure` | AK/SK expired or wrong -> `hcloud configure init` to re-enter |
| `InvalidRegion` | Wrong region code -> Check available regions at https://developer.huaweicloud.com/endpoint |
| `RequestTimeout` | Network issue -> Check proxy settings; try `hcloud configure set --timeout=30` |
| `SSLError` / `CertificateError` | Corporate proxy MITM -> Set `hcloud configure set --skip-secure-verify` (dev only) |

## Multi-Profile Support

```bash
# Create named profiles for multiple accounts
hcloud configure init --profile=prod
hcloud configure init --profile=dev

# Use a specific profile
hcloud --profile=prod ecs list

# Set environment variable
export HUAWEICLOUD_PROFILE=prod
```

## Security Considerations

- MUST NOT commit AK/SK to version control
- MUST use IAM Agency (temporary credentials) for production workloads
- MUST NOT echo AK/SK values in conversation or logs
- SHOULD rotate AK/SK every 90 days
- SHOULD use per-project IAM users with minimal permissions
