### CI 校验工具 (Phase 1 新增)

| 工具 | 作用 | 对标 AWS |
|------|------|----------|
| `tools/validate.py` | 校验 SKILL.md frontmatter (--- YAML delimiter)、marketplace.json 格式、plugin.json 字段完整性 | aws tools/validate.py |
| `tools/sync-plugin-skills.py` | 检查 skills/ 目录与 plugin.json 中声明的技能一致性 | aws tools/sync-plugin-skills.py |
| `.github/workflows/validate.yml` | CI pipeline: 每次 PR 自动运行 validate.py | — |

**validate.py 校验项**:

| 校验项 | 检查规则 | 失败动作 |
|--------|----------|---------|
| SKILL.md frontmatter | 文件以 `---` 开头，含 name/description/version 三字段 | 拒绝 |
| description 格式 | 含 `Use when...` 开头模式（警告） | 警告 |
| STOP 规则 | 文件含 `**STOP` 关键字 | 警告 |
| marketplace.json | 合法 JSON，plugins 数组非空 | 拒绝 |
| plugin.json | 合法 JSON，含 name/version/interface/mcpServers 字段 | 拒绝 |
| hcloud version | `hcloud version` >= 5.0.0（警告） | 警告 |
| 技能一致性 | skills/ 目录名与 SKILL.md 中 name 字段一致 | 警告 |

```bash
# CI 校验流程
python3 tools/validate.py --check-skills --check-marketplace --check-manifest
python3 tools/sync-plugin-skills.py --dry-run  # PR 中检查，非 dry-run 在 merge 时执行
```

## Phase 2: mcp-proxy-for-huawei (3 天)

> **实现策略**: ecs.py 作为第一个模板工具（含完整的参数校验、错误处理、审计日志模式），其余 16 个 service tool 按模板复制修改。每个 tool 约 1-2 小时（命令映射 + 参数适配 + 测试），3 天可完成全部 17 个工具。

### 步骤
1. 创建 Python 包骨架 (pyproject.toml + src/ 目录)
2. 实现 auth.py: AK/SK 读取 + 华为云签名
3. 实现 executor.py: subprocess 执行 hcloud 命令
4. 实现 tools/ecs.py: 第一个服务的 MCP Tool 注册 (验证可行性)
5. 实现其余 16 个服务的 MCP Tool 注册
6. 实现 utils/sanitize.py: 敏感信息脱敏
7. 实现 utils/logging.py: 审计日志
8. 发布到 PyPI 或内部 PyPI: mcp-proxy-for-huawei@1.0.0
